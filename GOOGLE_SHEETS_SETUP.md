# Подключение формы к Google Таблице

1. Создайте Google Таблицу. Отдельный лист `Заявки` создавать необязательно — скрипт сделает это сам.
2. Скопируйте ID таблицы из адреса между `/d/` и `/edit`.
3. В таблице откройте **Расширения → Apps Script**, вставьте содержимое `google-apps-script/Code.gs` и замените `ВСТАВЬТЕ_ID_GOOGLE_ТАБЛИЦЫ` на ID из шага 2.
4. Нажмите **Развернуть → Новое развертывание → Веб-приложение**. Выполнять от своего имени, доступ — **Все**. Подтвердите разрешения и скопируйте URL, заканчивающийся на `/exec`.
5. В GitHub откройте **Settings → Secrets and variables → Actions → New repository secret**. Создайте секрет `GOOGLE_SHEETS_WEB_APP_URL` со значением URL из шага 4.
6. Запустите workflow `Deploy to GitHub Pages` или отправьте новый коммит в `main`, затем сделайте тестовую заявку.

Для локальной проверки скопируйте `.env.example` в `.env.local`, подставьте URL веб-приложения и перезапустите Vite.

Таблица автоматически получает заголовки и сохраняет время, имя, телефон, согласие, часовой пояс, язык, страницу, источник перехода, UTM-метки, `yclid`, `gclid`, размер экрана, User Agent и уникальный ID заявки. Часовой пояс даёт приблизительный регион без подключения стороннего сервиса геолокации.
