# Сертификаты в Figma

Файл: https://www.figma.com/design/KJj0aX257jfLzYRU9SDdhU

Три фрейма 1055 × 1491: участник «Смотри» (2:7), номинант «Санта», «Запись в один клик» (2:8), призёр «Глазная клиника 3Z», 1-е место (2:9).
Данные: src/data/clinics.js и nominations в src/App.jsx. Период сохранён из образцов: III квартал 2026 года.
48 редактируемых текстовых слоёв. Фоны и фирменные логотипы растровые. Проверены итоговые изображения каждого фрейма.

Фоны participant.png, nominee.png, winner.png подготовлены встроенным ImageGen из трёх образцов пользователя. Итоговые изображения Figma: preview-0.png, preview-1.png, preview-2.png.

## Задание ImageGen

Для каждого исходного сертификата: удалить весь текст, буквы, логотип и знак логотипа, подписи, разделители и линии полей; бесшовно восстановить светло-сиреневый фон. Сохранить стеклянную награду справа внизу, подиум, бирюзовую дугу, тонкую белую дугу, свет, композицию и кадрирование. Портретные пропорции 1055 × 1491. Никакого текста. Фон предназначен для размещения под редактируемой типографикой Figma.
Варианты: кольцо для участника, медаль со звездой для номинанта, награда с вырезанным фирменным знаком и серебряным основанием для призёра.
